# BCA111P Lab Sheet-07

## String Handling using Built-in Functions in C++

This repository contains all 20 programs from BCA111P Lab Sheet-07.

### Topics
- strlen()
- strcpy()
- strcat()
- strcmp()
- strchr()
- strrchr()
- strstr()
- strncpy()
- String reverse and palindrome
- Word counting
- Anagram checking

### Important note
`strrev()` is not part of standard C++, so Questions 10 and 11 perform the same reverse operation manually while keeping the intended task.
